# portmzl.ru — каркас

Шаг 1 из пяти. Собран механизм защиты от неподтверждённых чисел, токены, компонент факта.
Страниц и текстов пока нет — это шаги 2–5.

---

## Что сделать прямо сейчас, по порядку

### 1. Положить ТЗ

Откройте `docs/tz.md`. Там заглушка. Замените её содержимым вашего файла
`02_tekhzadanie_sayta.md`. Без этого следующие шаги делать нельзя.

### 2. Проверить, что есть Node

В терминале, в этой папке:

```bash
node -v
```

Нужна версия 18.20.8, 20.3.0 или выше — то есть если увидите `v20` или `v22`, всё хорошо.
Если команда не найдена — поставьте Node.js LTS с nodejs.org и откройте терминал заново.

### 3. Поставить пакеты

```bash
npm install
```

Одна команда, качает Astro и Tailwind, занимает минуту-две. Появится папка `node_modules`
и файл `package-lock.json` — так и должно быть, трогать их не нужно.

### 4. Проверить механизм — это и есть смысл шага 1

**Сначала боевая сборка:**

```bash
npm run build
```

**Она должна упасть.** Это успех, а не поломка. В конце вывода ожидается примерно:

```
Факт «test_pending» имеет статус pending и не может быть опубликован.
Источник: Ждём письменного подтверждения. Примечание: Значение не подтверждено...
```

Если сборка прошла спокойно и написала `Complete!` — механизм не работает, напишите мне.

**Потом черновик:**

```bash
npm run dev
```

Терминал напишет адрес вида `http://localhost:4321`. Откройте в браузере
`http://localhost:4321/smoke`. Там должно быть пять блоков:

1. серая плашка со значением, китайской подписью, источником и красной пломбой ◉
2. то же значение моноширинным шрифтом внутри обычного предложения
3. красная заглушка «НЕТ ДАННЫХ · test_pending»
4. красная заглушка «РАСХОЖДЕНИЕ · test_disputed»
5. компактная красная метка внутри строки

Остановить сервер — `Ctrl + C`.

### 5. Шрифты (можно позже)

Пока в `public/fonts/` нет файлов, текст рисуется системным шрифтом. Вёрстка от этого
верная, вид — нет. Список нужных файлов: `public/fonts/README.md`.

## Правило номер один

Ни одно число не пишется прямо в разметку. Всегда так:

```astro
<Fact id="grain_capacity" />           плашка
<Fact id="grain_capacity" inline />    то же значение внутри строки текста
```

**id факта — это имя его файла.** `src/content/facts/grain_capacity.yaml` → `id="grain_capacity"`.

Значения нет — заводите файл со `status: pending` и пустым `value`. Не подставляйте
правдоподобное число, не округляйте, не оценивайте.

| status | dev | production |
|---|---|---|
| `confirmed` | рендерится | рендерится |
| `pending` | красная заглушка | **билд падает** |
| `disputed` | красная заглушка | **билд падает** |

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | черновик на вашем компьютере, обновляется на лету |
| `npm run build` | боевая сборка в `dist/`, падает на неподтверждённых фактах |
| `npm run preview` | посмотреть собранный результат |
| `npm run check` | проверка типов |
