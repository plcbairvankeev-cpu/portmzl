## Главное правило: числа

**Ни одно число не пишется прямо в разметку.** Все измеримые величины живут в `src/content/facts/*.yaml` и выводятся через `<Fact>`.

| status | Поведение |
|---|---|
| `confirmed` | рендерится |
| `pending` | билд падает в production |
| `disputed` | билд падает в production, в dev — красная плашка |

Если значение неизвестно — ставь `status: pending` и пустой `value`. **Не подставляй правдоподобное число, не округляй, не оценивай.** В исходных материалах есть расхождение в десять раз по объёму инвестиций; одна такая цифра на сайте обнуляет доверие ко всему проекту.

Проверка после любых правок контента:
```bash
npm run build   # должен падать, если на странице вызван pending-факт
```

## Дизайн — не отступать

```css
--ink: #0E1419      --port: #14459E     --steel: #2E4258
--seal: #B3241C     --concrete: #E4E2DD --paper: #F6F5F2   --line: #C6C8CB
```

Шрифты: `Onest` 800 (только H1–H2) · `Golos Text` 400/500 (проза) · `JetBrains Mono` 500 (все измеримые величины, номера реестров, коды, даты).

Разделение mono/проза содержательное, а не стилистическое: **в mono набирается всё, что можно проверить.** Не нарушать.

`--seal` используется **только** для пломбы проверяемости `◉` на плашке факта, где заполнено поле `registry`, и одной линии в шапке. Больше нигде.

Радиус 2 px. Границы 1 px `--line`. Теней нет. Градиентов нет.

Анимация: только полоса коридора при загрузке и появление плашек при скролле. `prefers-reduced-motion` отключает всё.

## Запреты

1. **Фотостоки.** Контейнеры на закате, рукопожатия, флаги. Нет своего фото — блок не выводится
2. **Карты с булавками.** Полоса коридора вместо карты. На `/contacts` — только внешняя ссылка
3. **Росконгресс, RC Complex Systems, логотипы третьих сторон.** Прав на упоминание нет
4. **Страница про мясо и морозильные мощности.** Мясная площадка не подтверждена. Формулировка на `/site` — «склады постоянной температуры», никогда «морозильные»
5. **«Номенклатура не ограничена», «любые товары», «под ключ любой груз».** Китайская сторона допускает товары по категориям и аккредитованным предприятиям
6. **Слово «представительство»** — только при `REPRESENTATIVE_STATUS_CONFIRMED=true` в `.env`. Иначе «партнёр в России»
7. **Тарифы, цены, сроки в сутках.** Все `pending`. Вместо них — «рассчитываем по маршруту и объёму»
8. **Секреты в репозитории.** Токен бота, SMTP, ключи — только `.env`, только в переменных окружения хостинга

## Тон текста

Плотно, конкретно, без продающих оборотов. Аудитория ежедневно работает с ТН ВЭД и актами досмотра; её убеждает плотность проверяемых данных, а не крупная типографика.

Не писать: «инновационные решения», «надёжный партнёр», «многолетний опыт», «под ключ», «мы поможем вам».
Писать: что есть, в каких величинах, откуда данные, что делать дальше.

Кнопки называют действие: «Рассчитать слот и срок», не «Отправить». Название действия сохраняется по всему пути: кнопка «Заказать расчёт» → подтверждение «Заявка отправлена».

Ошибки конкретны: не «произошла ошибка», а «Не отправилось. Напишите на info@portmzl.ru или в Telegram — заявку примем там».

Китайские фрагменты обёрнуты в `<span lang="zh-Hans">`, сверены с исходными документами посимвольно. Не переводить обратно с русского.
